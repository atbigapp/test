\n### 雷达供电\n\n将雷达连接至外部电源，并确认电源参数满足设备要求。\n\nCTSAI A100 常用供电范围如下：\n\n| 参数   | 规格                |\n| ---- | ----------------- |\n| 工作电压 | +6.0V ~ +18.0V DC |\n| 典型电压 | +12.0V DC         |\n| 整机功耗 | ＜3.6W             |\n\n上电前请确认：\n\n<img src="https://gonline-file-test.oss-cn-shenzhen.aliyuncs.com/file/png/2026-06-15/图片1_9270d2bf.png" alt="SuperRadar Open-source millimeter-wave radar" height="auto" width="50%"></img>\n\n\n* 电源正负极连接正确。\n* 供电电压处于设备允许范围内。\n* 雷达线束连接牢固。\n* 雷达安装方向与实验场景保持一致。\n\n### CAN-FD 接线\n\n使用 USB-CAN FD 盒连接雷达与 PC。\n\n雷达主要通信信号包括：\n\n| 信号     | 说明    |\n| ------ | ----- |\n| VCC    | 电源正极  |\n| GND    | 电源地   |\n| CAN0-H | CAN 高 |\n| CAN0-L | CAN 低 |\n\n常用连接方式如下：\n![image.png](https://gonline-file-test.oss-cn-shenzhen.aliyuncs.com/file/png/2026-06-15/image_e57a93b4.png 'image.png')\n\n\n```text\n雷达 CAN0-H  →  USB-CAN FD 盒 CAN1-H\n雷达 CAN0-L  →  USB-CAN FD 盒 CAN1-L\n雷达 VCC     →  电源正极\n雷达 GND     →  电源地\n```\n\n\n\nUSB-CAN FD 盒接入电脑后，即可进入驱动安装流程。\n\n\n## 安装 USB-CAN FD 驱动\n\n### 选择驱动安装程序\n\n进入 GitHub 仓库中的驱动目录：\n\n```text\ntools/USBCAN_Driver/\n```\n\n根据电脑系统位数选择对应安装程序：\n\n| 系统类型         | 安装程序           |\n| ------------ | -------------- |\n| 32 位 Windows | `DPInst32.exe` |\n| 64 位 Windows | `DPInst64.exe` |\n\n大多数 Windows 10 / Windows 11 电脑为 64 位系统，可直接运行：\n\n```text\nDPInst64.exe\n```\n\n### 确认驱动安装成功\n\n驱动安装完成后，打开 Windows 设备管理器，确认可以看到 USB-CAN FD 相关设备。\n\n如果设备管理器中显示类似以下设备名称，则说明驱动安装成功：\n\n```text\nGCAN USBCANFD Device\n```\n\n若设备未出现，请检查：\n\n* USB-CAN FD 盒是否正确连接电脑。\n* USB 数据线是否正常。\n* 驱动安装程序是否与系统位数匹配。\n* 设备管理器中是否存在未识别设备。
